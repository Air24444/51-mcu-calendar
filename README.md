\# 51 单片机多功能万年历



基于 AT89C52 单片机的多功能万年历，使用 Keil C51 开发和 Proteus 仿真。



\## 功能

\- 公历日期、时间、星期显示

\- 农历与闰月显示

\- 按键设置日期、时间和温度阈值

\- DS1302 实时时钟

\- DS18B20 温度检测

\- AT24C512 掉电保存

\- LCD1602 显示

\- 高温报警与风扇控制



\## 开发环境

\- Keil uVision / C51

\- Proteus 8

\- MCU：AT89C52



\## 目录结构

\- `仿真万年历代码/`：Keil 工程和 C51 源码

\- `万年历最终版仿真.pdsprj`：Proteus 仿真工程

\- `要求.jpg`：课程设计要求



\## 编译与仿真

1\. 使用 Keil 打开 `仿真万年历代码/project.uvproj` 并编译。

2\. 确保生成 `仿真万年历代码/Objects/project.hex`。

3\. 使用 Proteus 打开 `万年历最终版仿真.pdsprj` 并运行仿真。

# 51 单片机多功能万年历

基于 AT89C52 单片机的多功能万年历设计，使用 Keil C51 开发，并通过 Proteus 进行电路仿真。

系统能够显示公历、农历、星期、时间和温度，支持按键修改时间及温度阈值，并具有掉电保存、高温报警和风扇控制功能。

## 功能特性

- 公历日期显示：年、月、日、星期
- 24 小时制时间显示：时、分、秒
- 自动判断闰年
- 公历与农历显示切换
- 支持农历闰月显示
- 按键修改年、月、日、时、分
- DS18B20 温度检测
- 温度报警阈值设置
- AT24C512 EEPROM 掉电保存
- 温度超限时蜂鸣器报警
- 温度超限时自动启动风扇
- LCD1602 液晶显示

## 硬件组成

| 模块 | 器件 | 功能 |
| --- | --- | --- |
| 主控芯片 | AT89C52 | 系统控制与数据处理 |
| 实时时钟 | DS1302 | 日期和时间计时 |
| 温度传感器 | DS18B20 | 环境温度检测 |
| 存储芯片 | AT24C512 | 保存时间及温度阈值 |
| 显示模块 | LCD1602 | 显示日期、时间、农历和温度 |
| 按键模块 | 4 个独立按键 | 设置日期、时间及阈值 |
| 报警模块 | 蜂鸣器 | 高温报警 |
| 执行模块 | 风扇电机 | 高温时自动启动 |

## 按键说明

| 按键 | 引脚 | 正常模式 | 设置模式 |
| --- | --- | --- | --- |
| SET | P2.3 | 进入设置模式 | 保存设置并退出 |
| SEL | P2.2 | 无 | 切换需要修改的项目 |
| ADD | P2.1 | 无 | 增加当前项目数值 |
| SUB/农历 | P2.0 | 切换公历和农历 | 减小当前项目数值 |

设置模式可依次调整：

1. 年
2. 月
3. 日
4. 时
5. 分
6. 温度报警阈值

退出设置模式后，时间会写入 DS1302，并同时保存到 AT24C512 中。

| `Lunar.c` | 公历转农历 |
| `DeviceCtrl.c` | 蜂鸣器和风扇控制 |
| `delay.c` | 延时函数 |
